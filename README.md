# Ampify ⚡

**Ampify** is a lightweight, purely vibe-coded utility designed to give you direct, real-time manual control over your device's charging speed and current. Built for rooted Android devices, it lets you tweak your charging values on the fly without needing reboots or script reloads.

---

### ✨ Features

* **Instant Current Regulation:** Adjust charging current manually in real time. Changes apply immediately—no reboot or module reinstall required.
* **Full Manual Flexibility:** You decide the speed—dial it down manually if the phone is getting warm, or crank it up when you need a quick top-up.
* **Active & Idle Drain Monitor:** Real-time battery drain stats integrated directly into your status bar to keep track of active usage and deep-sleep standby.
* **Drain vs. Time Analytics:** In-depth graphs plotting discharge over time to help you visualize battery consumption patterns.
* **Battery Lifespan Preservation:** Manually capping speeds helps reduce stress on the battery, especially for overnight charging or heavy usage while plugged in.

### 📋 Prerequisites

* Android device with root access (Magisk, KernelSU, or APatch).
* Kernel support for modifying charging current nodes (`/sys/class/power_supply/*`).
